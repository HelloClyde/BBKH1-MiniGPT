## 完整固件模拟器

环境：H1/Y100 V1.41 完整固件、64 MiB SDRAM、私有 NAND 副本。已验证实际模型回答与主机参考一致、原生拼音/英文输入、编辑保存/取消与重复打开、例题与 UTF-8 文件提问、取消 prefill、气泡滚动/触屏拖动、新聊天、日志关闭、返回退出；回答文件未创建或覆盖。INT8 可选缓存预热和读取方式短测的跳过路径也生成了正确回答。字体截图是实际呈现的画面。

本次 INT8 模拟器选择 4 层缓存，32-token 首问 / 16-token 回答实际读取 193,159,168 字节，定位 16 次；同路径 3 层缓存应读取 241,448,960 字节（4 层相较 3 层少读取 20%）。同一中文问题复用 17/28 前缀词元，prefill 从 133 降到 81 raw tick，减少约 39.1%。以上是特定模拟器观测，不代表真机提速。

INT4 本次模拟器全权重常驻。双词元 MXU 与前缀复用已验证；同题 prefill 在旧测量中为 198 → 78 raw tick。低位数量化可能改变回答质量，INT4 与 INT8 的输出不保证相同。

## 主机与 CI

主机测试验证量化格式/CRC、112 组分词、NumPy 数学对照、流式/内存模式一致、完整 KV/logits、解码、前缀共享/缩短/改变/取消、分配失败回退，以及各缓存层数和缓存方式选择的读量与释放。MXU 叶函数单独验证整数结果、CP0/寄存器保护和指令路径。DMA 的 RAM/CP0/读回调使用替身；不作为真实 NAND 异步速度证明。

Actions 构建/主机测试不运行固件。Release 的打包器核对 BDA/模型散列与上述固定值；若代码或工具链导致 BDA 改变，则需要更新版本并补充新的运行验证记录，不能继承旧散列的通过结论。

## 实机

此前 INT8 0.3.5 的真实设备日志显示 3 层缓存和真实 DMA 等待回调进度。本次发布的 INT8 0.3.6 与 INT4 0.4.2 使用模拟器运行证据，未把旧版实机记录当作新版性能/稳定性验证。实际堆碎片、NAND 等待和其他固件服务负载决定缓存层数与短测选择；新版速度应运行后查看自己的 minigpt.log。程序没有超频。
